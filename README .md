# 🤝 compass Bot

**Telegram-бот для поиска сокомандников на мероприятия кампуса**

---

## 📌 О проекте

**Compass Bot** — это цифровой помощник для студентов, который помогает находить команду для участия в любых мероприятиях: хакатоны, квизы, спортивные соревнования, конференции и другие события кампуса.

### ❓ Проблема
Студенты часто хотят участвовать в мероприятиях, но не могут найти команду. Существующие способы (общие чаты, доски объявлений) неэффективны и разрозненны.

### 💡 Решение
Telegram-бот, где студент может:
- Создать заявку на поиск команды
- Найти существующие заявки по ролям и мероприятиям
- Откликнуться на заявку и получить контакт автора
- Отслеживать свои активные заявки

## 🛠 Технологический стек

| Компонент | Технология | Назначение |
|-----------|------------|------------|
| **Язык программирования** | Python 3.11+ | Логика бота |
| **Фреймворк** | aiogram 3.x | Работа с Telegram Bot API |
| **База данных** | PostgreSQL / SQLite | Хранение пользователей и заявок |
| **Деплой** | Render.com | Хостинг и автоматический запуск |




## 🤖 Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Запустить бота / главное меню |
| `/profile` | Создать заявку или изменить заявку |
| `/bookmarks` | Посмотреть закладки |
| `/reviews` | Посмотреть отзывы о себе |
| `/pause` | Скрыть свою анкету |
| `/resume` | Снова показать анкету |
| `/cancel` | Прервать текущий шаг |
| `/help` | Помощь и список всех команд |
