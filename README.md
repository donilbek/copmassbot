# Telegram-бот «Поиск команды»

Минимальный рабочий прототип Telegram-бота для поиска единомышленников, команд и ИТ-специалистов в проекты. Написан на асинхронном фреймворке **aiogram 3** с использованием **SQLite** в качестве базы данных.

## Базовый функционал

- **Выбор режима.** Гибкое переключение между сценариями «Ищу команду» и «Ищу человека в проект».
- **Создание анкеты.** Заполнение профиля участника: ФИО, вуз и курс, роль, технологический стек, желаемый формат участия, статус поиска, соцсети, телефон и описание своих проектов.
- **Карточка проекта.** Автор идеи публикует проект: название, описание, требуемые роли (мультивыбор кнопками), тематика, стадия и формат участия.
- **Просмотр карточек.** Показ проектов, подходящих под выбранную роль, по одному с кнопками действий; просмотренные карточки не повторяются.
- **Система мэтчинга.** Отклик уходит владельцу проекта вместе с анкетой кандидата; после кнопки «Принять» контакты открываются обеим сторонам.
- **Закладки.** Сохранение понравившихся проектов, чтобы откликнуться позже.
- **Отзывы.** После мэтча участники могут оставить отзыв друг о друге, отзывы видны в карточке соискателя.
- **Управление профилем.** Возможность поставить анкету на паузу или возобновить её показ в общем поиске.
- **Обработка некорректного ввода.** Валидация каждого поля анкеты и проекта, подсказки при ответе текстом вместо кнопок и понятные ответы на стикеры, голосовые, файлы и контакты.

## Структура проекта

```
tgbotcompass/
├── bot.py               # точка входа, регистрация роутеров и middleware
├── database.py          # работа с SQLite и миграции
├── states.py            # состояния FSM (анкета, проект, поиск, отзыв)
├── validators.py        # проверки ввода и тексты ошибок
├── middlewares.py       # фильтр нетекстовых сообщений (голос, стикеры, файлы)
├── handlers/
│   ├── common.py        # /start, /help, /cancel, главное меню, отклики
│   ├── profile.py       # анкета соискателя, пауза/возобновление
│   ├── project.py       # создание проектов, закладки
│   ├── browse.py        # просмотр карточек, отклики, мэтчи
│   ├── review.py        # отзывы о партнёрах по проекту
│   └── fallback.py      # ответ на свободный текст в меню
├── requirements.txt
└── .env.example
```

## Шаг 1. Получить токен бота

1. В Telegram напиши **@BotFather**.
2. Команда `/newbot`.
3. Введи имя бота (отображаемое) и username (обязательно заканчивается на `bot`, например `team_match_test_bot`).
4. BotFather пришлёт токен вида `123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxx`. Сохрани его — он понадобится дальше.

## Шаг 2. Установить окружение

Нужен Python 3.10+.

```bash
cd tgbotcompass
python -m venv venv
venv\Scripts\activate          # на macOS/Linux: source venv/bin/activate
pip install -r requirements.txt
```

## Шаг 3. Настроить токен

```bash
copy .env.example .env         # на macOS/Linux: cp .env.example .env
```

Открой `.env` и вставь свой токен:

```
BOT_TOKEN=123456789:AAExxxxxxxxxxxxxxxxxxxxxxxxxxxxx
```

## Шаг 4. Запустить бота

```bash
python bot.py
```

Если всё ок, в консоли появится `Бот запускается...`. База данных `bot.db` создастся автоматически при первом запуске.

Открой Telegram, найди своего бота по username и нажми **Start** — должно прийти приветственное сообщение.

## Команды бота

| Команда | Назначение |
| --- | --- |
| `/start` | Запустить бота и открыть главное меню |
| `/profile` | Создать или изменить анкету |
| `/bookmarks` | Посмотреть сохранённые проекты |
| `/reviews` | Посмотреть отзывы о себе |
| `/pause` | Скрыть свою анкету из поиска |
| `/resume` | Снова показывать анкету |
| `/cancel` | Прервать текущий шаг и вернуться в меню |
| `/help` | Список команд |

## Как проверить логику мэтчинга

1. С первого аккаунта заполни анкету (`/profile`), затем «📢 Ищу человека в проект» → «Создать проект».
2. Со второго аккаунта (или попроси друга) заполни анкету и выбери «🔍 Ищу команду».
3. Второй аккаунт выбирает роль, проходит фильтр и видит карточку проекта → жмёт «Откликнуться».
4. Первому аккаунту приходит анкета кандидата с кнопками «Принять» / «Отклонить».
5. После «Принять» обеим сторонам приходят контакты и предложение оставить отзыв.

## Обработка ошибок ввода

Бот не оставляет пользователя без ответа ни на одном шаге:

- **Нетекстовые сообщения.** Голосовые и видеокружки, стикеры и GIF, фото и файлы, пересланные контакты перехватываются middleware до всех обработчиков — на каждый тип свой ответ.
- **Ответ текстом вместо кнопок.** В выборе роли, статуса, опыта, ролей проекта и при просмотре карточек бот повторно присылает нужные кнопки с подсказкой.
- **Валидация полей.** ФИО (минимум два слова, без цифр и спецсимволов), вуз (3–120 символов), стек, формат участия, соцсети, телефон (код страны и не менее 10 цифр), название и описание проекта (до 500 символов), тематика, стадия и формат.
- **Бессмысленный ввод.** Отсекаются три и более одинаковых символа подряд, прогоны по клавиатуре (`ывапывап`, `asdfgh`) и наборы букв без гласных.
- **Свободный текст в меню.** Любое неопознанное сообщение получает ответ с клавиатурой главного меню.
- **Незаполненная анкета.** Разделы «Ищу команду» и «Ищу человека в проект» закрыты до заполнения профиля — бот предлагает кнопку «Заполнить анкету».

## Деплой

- **VPS** (Timeweb, Selectel, Hetzner и т.п.) + `systemd`-сервис или Docker + `docker-compose`, чтобы бот работал 24/7.
- **Polling vs Webhook.** Сейчас бот работает через polling (проще для старта). Для вебхука понадобится домен с HTTPS и веб-сервер (nginx + aiohttp).
- Для продакшена стоит вынести `bot.db` в отдельный volume и заменить `MemoryStorage` на Redis, чтобы состояния анкет не терялись при перезапуске.
