# 🤝 compass Bot

**Telegram-бот для поиска сокомандников на мероприятия кампуса**

---

## 📌 О проекте

**TeamFinder** — это цифровой помощник для студентов, который помогает находить команду для участия в любых мероприятиях: хакатоны, квизы, спортивные соревнования, конференции и другие события кампуса.

### ❓ Проблема
Студенты часто хотят участвовать в мероприятиях, но не могут найти команду. Существующие способы (общие чаты, доски объявлений) неэффективны и разрозненны.

### 💡 Решение
Telegram-бот, где студент может:
- Создать заявку на поиск команды
- Найти существующие заявки по ролям и мероприятиям
- Откликнуться на заявку и получить контакт автора
- Отслеживать свои активные заявки

## 🛠 Технологический стек

| Компонент | Технология | Назначение |
|-----------|------------|------------|
| **Язык программирования** | Python 3.11+ | Логика бота |
| **Фреймворк** | aiogram 3.x | Работа с Telegram Bot API |
| **База данных** | PostgreSQL / SQLite | Хранение пользователей и заявок |
| **Контейнеризация** | Docker + Docker Compose | Универсальный запуск на любой платформе |
| **Деплой** | Render.com | Хостинг и автоматический запуск |
| **CI/CD** | GitHub Actions | Автоматический деплой при пуше |
| **Логирование** | logging + отправка в админ-чат | Мониторинг работы бота |




## 🤖 Команды бота

| Команда | Описание |
|---------|----------|
| `/start` | Зарегистрироваться в системе |
| `/create` | Создать заявку на поиск команды |
| `/find` | Найти активные заявки (с фильтром по роли/мероприятию) |
| `/my` | Посмотреть свои активные заявки |
| `/match [ID]` | Откликнуться на заявку |
| `/events` | Список актуальных мероприятий кампуса |
| `/help` | Помощь и список всех команд |
